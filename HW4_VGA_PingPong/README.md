# HW4：根據乒乓 LED 位置顯示對應圖案

這個作業是將 HW3 的「乒乓球遊戲」邏輯與 VGA 顯示結合。讓FPGA開發板上的 LED 會動，還讓 VGA 螢幕上的畫面跟著 LED 的位置一起同步移動。

## 1. 畫面顯示邏輯
螢幕上主要顯示兩個部分，使用了不同的繪圖方式：

* **綠色的乒乓球（幾何運算）：**
    * 公式：$$(hCount - h\_shift)^2 + (vCount - 400)^2 \le ball\_r^2$$。
    * 透過改變 `h_shift` 的數值，球就會在螢幕上左右移動。
* **背景圖案（BRAM 讀取）：**
    * 使用 **blk_mem_gen_0** 這個 IP Core 來儲存圖片資料。
    * 當 VGA 掃描到指定區域時，程式會去 BRAM 抓出像素資料（`block_out`）並顯示出來。

## 2. 遊戲功能與同步
* **LED 同步：** 開發板上的 8 顆 LED 代表球的位置，這跟 VGA 螢幕上的球移動是完全同步的。
* **按鈕控制：** * `btn_l` / `btn_r`：用來發球與擊球回擊。
    * `rst`：重置遊戲。
* **隨機變速：** 我在程式裡加了 `lfsr` 邏輯，讓球在往返時的速度會產生隨機變化，增加遊戲的難度。

## 3. 狀態機 (FSM) 設計
* **initial**：遊戲初始狀態，球停在左邊。
* **move_right / move_left**：球正在移動，VGA 座標會跟著加減。
* **win_l / win_r**：當有人漏接球時進入得分狀態，LED 會顯示當前的比數。
* **ready_mr / ready_ml**：得分後的預備發球狀態。
